Shell commands

claudeStart interactive session
claude "prompt"Start with an opening prompt
claude -p "prompt"One-off query, print, exit
claude -cContinue most recent conversation
claude -rPick a conversation to resume
claude --permission-mode planStart in plan mode
claude --permission-mode autoStart in auto mode
claude --agent <name>Run a session as a subagent

Prompt patterns

Useful prompts you can reuse

Bug fix

"[symptom]. Check [location]. Write a failing test that reproduces it, then fix the root cause. Don't suppress the error. Show me the test output."

Feature work

"Implement [feature]. Follow the pattern in @[example-file]. Don't add libraries that aren't already in the project. Write tests for [cases], run them, and fix failures."

Investigation

"Use subagents to investigate [question]. Start in [directory]. Report a summary, not file contents."

Review

"Use a subagent to review [the diff] against [PLAN.md / the requirements]. Flag only gaps affecting correctness or the stated requirements. Ignore style preferences."
